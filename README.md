# API de Catálogo de Plantas

Esta aplicação será uma API para cadastrar e consultar plantas.

A ideia é permitir que o usuário registre informações simples sobre suas
plantas, como nome, espécie, frequência de rega e local onde ela fica.

Inicialmente, o projeto terá apenas um endpoint de teste. Nas próximas
etapas, serão implementadas as funcionalidades para criar, listar,
atualizar e remover plantas.
